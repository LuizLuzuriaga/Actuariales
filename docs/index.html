Un lunes cualquiera. Un actuario. El fin del mundo, entre medias.

Una mañana de trabajo en primera persona: te despiertas, coges el cercanías, llegas a la oficina y cuadras reservas mientras Madrid se va a pique. Hay curvas de mortalidad, una bacteria negra, zombis y ocho finales. Cada cosa que haces suma o resta descuido, y el descuido decide cómo acaba el día.

Jugar con el móvil como mando

Escanea el código con el móvil: se abre un mando con dos joysticks y botones, y tu móvil mueve al personaje de esta pantalla.

Se abre una sala temporal solo cuando despliegas este panel.

~20 min

  • Ordenador: clic para capturar el ratón · WASD moverte · Shift correr · E interactuar · Q/R asomarte · C agacharte · F empujar · clic para disparar · Esc soltar
  • Mando: sticks para moverte y mirar · A interactuar · X empujar · RT disparar · B agacharte · Y cámara
  • Móvil: joystick a la izquierda (mantenlo 3 s hacia delante para correr) y arrastra a la derecha para mirar
